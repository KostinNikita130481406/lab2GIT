#  О проекте:

# 1. Назначение
Предметной областью разрабатываемой информационной системы является деятельность ремонтной мастерской, специализирующейся на ремонте электротехники. Основной задачей мастерской является прием и учет заявок клиентов на ремонт неисправной электротехники.

# 2. Регистрация клиентов и заявок
При обращении клиента в мастерскую сотрудник регистрирует новую заявку. Для каждого клиента в системе хранится его ФИО. Один клиент может обращаться в мастерскую несколько раз.

# 3. Структура данных заявки
В заявке указываются уникальный номер заявки, дата ее поступления, сведения о клиенте, вид электротехники, ее производитель и описание неисправности. При каждой новой заявке информация об электротехнике создается заново.

# 4. Автоматическое распределение заявок
В мастерской работает несколько сотрудников. Для каждого сотрудника в системе хранится его ФИО. При создании заявки система смотрит заняты ли ввсе сотрудники или нет. Если есть свободный сотрудник заявка назначается ему если же нет то назначается сотруднику с наименьши колличеством заявок. Один сотрудник может одновременно работать только с одной открытой заявкой. После закрытия назначенной ему заявки сотрудник становится свободным и может принять новую заявку.

# 5. Закрытие заявок
Закрытие заявки выполняет только тот сотрудник, которому она была назначена. При закрытии заявки в системе фиксируется дата закрытия. До момента закрытия дата закрытия отсутствует.

# 6. Функционал системы и поиск
Информационная система предназначена для хранения и просмотра зарегистрированных заявок. Пользователь системы может просматривать список заявок и выполнять их поиск по номеру заявки, ФИО клиента и виду электротехники.

# 7. Заключение
Таким образом, разрабатываемая информационная система обеспечивает централизованный учет заявок на ремонт электротехники, хранение сведений о клиентах, электротехнике и сотрудниках, автоматическое распределение заявок между сотрудниками, а также фиксацию дат поступления и закрытия заявок.
