#  О проекте:
Проект представляет  собой  систему обеспечивающаю централизованный учет заявок
на ремонт электротехники, хранение сведений о клиентах, электротехнике
и сотрудниках, автоматическое распределение заявок между свободными сотрудниками,
а также фиксацию дат поступления и закрытия заявок.

# Принцип работы:
Основной задачей мастерской является прием и учет заявок
клиентов на ремонт неисправной электротехники.
